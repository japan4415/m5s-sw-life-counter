## 機能要件

FaB のルール上、ヒーローカードに記載されたライフ値を使用するため、開始ライフは 20/40 の定型値だけでなく任意値の設定が必須である。ライフは開始値を超えて増加でき、0 未満にはならない。

| ID | 要件 | 詳細 | MVP |
|----|------|------|-----|
| FR-01 | 上下 2 プレイヤーのライフ独立管理 | 画面上半分と下半分でそれぞれのプレイヤーのライフを独立して表示・変更できる | Yes |
| FR-02 | 開始ライフの選択 | 20 / 40 / 任意値から開始ライフを選択できる。FaB のヒーローカード記載値に対応するため任意値入力は必須 | Yes |
| FR-03 | ライフの下限制約 | ライフは 0 未満にならない。0 に到達した場合は警告表示のみとし、操作を制限しない（Undo・増加・メニュー操作はすべて可能） | Yes |
| FR-04 | 開始値を超えるライフ増加 | ライフは開始値を上限とせず、開始値を超えて増加できる | Yes |
| FR-05 | 外周スライドによるライフ増減 | 円形画面の外周リングをスライドしてライフを増減する。時計回りで増加、反時計回りで減少。デフォルト 36 度/ライフ（Phase 1 で確定）。Sensitivity 設定で 5 / 10 / 20 ライフ/周に変更可能 | Yes |
| FR-06 | スライド開始地点によるプレイヤー選択 | タッチ開始地点の y 座標が中心（234px）未満なら上側プレイヤー、以上なら下側プレイヤーを操作対象とする。操作開始後は対象プレイヤーを固定し、移動中に境界を越えても変更しない | Yes |
| FR-07 | 1 スライド = 1 履歴 | 1 回のスライド操作全体（指が触れてから離れるまで）を 1 件の操作として履歴に登録する | Yes |
| FR-08 | Undo | Button A 短押しで直前の操作を Undo し、操作前の値へ戻す。Undo 自体もイベントとして記録される | Yes |
| FR-09 | タッチロック | Button B 短押しでタッチ入力のみを無効化する。物理ボタン（Undo・メニュー等）は有効のまま | Yes |
| FR-10 | ゲームメニュー | A+B 長押しでメニューを表示する | Yes |
| FR-11 | Resume | ゲームメニューからゲーム画面へ戻る | Yes |
| FR-12 | History | 直近のライフ変更履歴（最大 64 件）を表示する | Yes |
| FR-13 | Set Life | Setup 画面へ遷移し、現在のプレイライフを起点に開始ライフを変更する。B 長押しで新しい試合を開始し履歴をクリアする。New Game 統合後（#15）は開始ライフを変更して試合を始める唯一の経路である | Yes |
| FR-14 | Rematch | 同じ開始ライフで試合をやり直す。長押し確認を要求する | Yes |
| FR-15 | ~~New Game~~ | Rematch に統合（#15）。Set Life メニューで開始ライフを変更できるため、独立した New Game の存在意義がなくなった。Rematch が同じ開始ライフでの試合やり直しを担う | - |
| FR-16 | ~~Swap Sides~~ | 使用しないため削除（#16）。上下プレイヤーの入れ替え機能は実運用で不要と判断された | - |
| FR-17 | About | ファームウェアバージョンを表示する | Yes |
| FR-18 | 再起動後の状態復元 | 再起動後に最後に確定した状態（ライフ・開始ライフ・上下の対応・タッチロック状態・履歴・ゲーム進行中フラグ）を復元する | Yes |
| FR-19 | 振動フィードバック | 操作に応じた振動パターンで触覚フィードバックを提供する。音声は使用しない | Yes |
| FR-20 | Tournament Mode | 標準動作モードとして Tournament Mode を採用し、Wi-Fi / Bluetooth を初期化しない。外部通信を一切行わない | Yes |
| FR-21 | バッテリー残量表示 | 画面上にバッテリー残量を表示する | Yes |
| FR-22 | バッテリー低下警告 | バッテリー残量 20% 以下で警告表示、10% 以下で定期警告振動を行う | Yes |
| FR-23 | プレビュー表示 | スライド操作中はプレビュー値と差分（例: `-4`）を画面中央に表示し、指を離した時点で確定する | Yes |
| FR-24 | 操作キャンセル | スライド中に指を中央方向へ引き込む（半径 145px 未満・設計上の初期値）と操作をキャンセルできる | Yes |
| FR-25 | セットアップ画面 | 初期ライフ設定画面で 20 / 40 / CUSTOM を選択し、START は 1.5 秒長押しで確定する | Yes |
| FR-26 | 復元プロンプト | 起動時に保存済みゲームがある場合、自動的に復元する（NVS 永続化による自動復元。新規試合はメニューの Rematch または Set Life で開始） | Yes |
| FR-27 | 減光と画面管理 | ゲーム進行中は画面を消灯しない。90 秒無操作で低輝度へ減光し、入力で通常輝度へ復帰する | Yes |
| FR-28 | スリープ / 復帰 | 電源ボタンでスリープ・復帰できる。スリープ移行前に状態を保存する | Yes |
| FR-29 | モバイル連携（BLE） | BLE 経由でスマートフォンアプリと接続し、試合設定・履歴閲覧・試合記録を行う | Future |
| FR-30 | クラウド同期 | スマートフォンアプリ経由でクラウドへ試合記録をバックアップ・同期する | Future |
| FR-31 | Observer Mode | 2 台目のスマートフォンを Observer として接続し、試合を閲覧する | Future |
| FR-32 | Casual Mode | スマートフォンからのライフ修正・Undo・試合中メモを許可するモード | Future |
| FR-33 | 感度設定 | メニューの Sensitivity からスライド感度を 5 / 10 / 20 ライフ/周（72 / 36 / 18 度/ライフ）に変更できる。設定は NVS に永続化され、デフォルトは 10 ライフ/周（従来動作と同一） | Yes |

## 非機能要件

| ID | カテゴリ | 要件 | 基準 |
|----|---------|------|------|
| NFR-01 | 視認性 | 60〜80cm 離れた位置からライフの数字が読める | 大会テーブル幅を想定。フォントサイズ・コントラストで担保 |
| NFR-02 | 応答性 | 入力から画面反映までの体感遅延がない | 非ブロッキングのイベントループと PSRAM 上の全画面バッファによる描画方式で担保する。実測は Phase 0 で実施 |
| NFR-03 | 稼働時間 | 最低 4 時間 / 推奨 8 時間の連続稼働 | 測定条件: Wi-Fi/Bluetooth 無効・輝度 30〜40%・振動有効。**実測必須**。バッテリー容量は 450mAh（公式値）。未達時は輝度設定見直しまたは小型 USB バッテリー使用を検討 |
| NFR-04 | 耐障害性 | 電源断で失われてよいのは「確定途中だった最後の 1 操作」のみ | NVS ローテーション保存と CRC32 検証で担保。破損時は 1 つ前の正常なレコードへフォールバック |
| NFR-05 | 公平性 | 上下双方から常に同じ情報が見える | 上半分を 180 度回転描画し、双方のプレイヤーが同一の情報を確認できる |
| NFR-06 | 誤操作耐性 | 単一操作でリセットできない | Rematch は長押し確認を要求。タッチロック機能を提供 |
| NFR-07 | 保守性 | 実機で決まる閾値定数は 1 箇所に集約 | `config/app_config.hpp` に外周リング半径・感度角・最低移動角・キャンセル半径・振動時間等を集約 |
| NFR-08 | オーバーフロー安全性 | ライフ値の算術演算でオーバーフローしない | `int64_t` キャストによる中間計算で対応。UINT32_MAX 近傍の単体テスト必須 |
| NFR-09 | 無線不使用 | Tournament Mode で Wi-Fi / Bluetooth を起動しない | 無線モジュールを初期化しないことで消費電力削減と大会規定準拠を両立 |
| NFR-10 | 画面常時表示 | ゲーム進行中は画面を完全消灯しない | 減光は許容するが消灯は禁止。セットアップ中のみ 5 分無操作で画面 OFF |
| NFR-11 | 音声不使用 | 音声出力を使用しない | 大会環境を考慮し、すべてのフィードバックを振動で行う |

## 制約

### FaB 大会規定

Flesh and Blood の大会規定（Tournament Rules and Policy）に基づく制約である。

| 制約 | 内容 |
|------|------|
| ドラフト中の電子機器使用不可 | Competitive / Professional REL のドラフト中は電子機器の使用が禁止されている |
| ヘッドジャッジの追加制限 | ヘッドジャッジは電子機器の使用について追加の制限を設けることができる |
| ライフ差異の解決 | プレイヤー間でライフ値に差異が生じた場合、物理記録（ペンと紙）が優先される |
| 事前確認の義務 | 大会での使用前にヘッドジャッジへ電子ライフカウンターの使用可否を確認すること |

### 運用上の制約

| 制約 | 内容 |
|------|------|
| 物理記録の携帯 | 電子カウンター使用時も、ペンと紙または物理カウンターを必ず携帯すること |
| 戦略情報の非記録 | カード名・手札・ピッチ順・戦略メモを記録しない（Tournament Mode） |

### ハードウェア制約

| 制約 | 内容 |
|------|------|
| バッテリー容量 | 450mAh（公式値） |
| 画面サイズ | 1.75 インチ円形 AMOLED、468 x 468 px（実測値。公式仕様は 466 x 466 px） |
| 物理ボタン | 2 個（KEYA: GPIO2、KEYB: GPIO1）+ 電源ボタン |
| Flash | 16MB |
| PSRAM | 8MB |

## 受入基準（MVP）

一次資料で定義された 12 項目をそのまま掲載する。各項目に対応する要件 ID を紐づける。

- [ ] AC-01: 上下それぞれのライフを独立して変更できる → FR-01, FR-05, FR-06
- [ ] AC-02: ライフが 0 未満にならない → FR-03
- [ ] AC-03: 開始ライフを超えて増加できる → FR-04
- [ ] AC-04: 20、40、任意値から開始できる → FR-02, FR-25
- [ ] AC-05: 直前の操作を正確に Undo できる → FR-08
- [ ] AC-06: スライド操作全体を 1 回で Undo できる → FR-07, FR-08
- [ ] AC-07: タッチロックが機能する → FR-09
- [ ] AC-08: 再起動後に最後に確定した状態を復元できる → FR-18, FR-26
- [ ] AC-09: リセットには長押し確認が必要 → FR-14, NFR-06
- [ ] AC-10: 上下双方から同じ情報を確認できる → NFR-05
- [ ] AC-11: Tournament Mode では無線通信を開始しない → FR-20, NFR-09
- [ ] AC-12: 1000 回の連続ランダム操作でモデルと表示が一致する → NFR-02

## スコープ外

以下の機能は MVP のスコープに含めない。

| 機能 | 理由・備考 |
|------|-----------|
| ヒーローデータベース | 任意値入力（FR-02）で対応する |
| カード画像表示 | ライフカウンターの本質的機能ではない |
| ターンタイマー | FaB の試合進行管理は本アプリの範囲外 |
| 毒・装備カウンター | MVP では純粋なライフカウンターに限定する |
| スマートフォン連携 | 将来フェーズとして [モバイル連携設計](./10-mobile-integration.md) で扱う |
| 2 台同期 | スマートフォン連携と同様に将来フェーズ |

## 未確定・要検証の要件

一次資料の未解決事項のうち、要件に直接関わるものを以下に整理する。

| 項目 | 現状 | 検証方法 |
|------|------|---------|
| 連続稼働時間 | 目標値のみ（最低 4 時間 / 推奨 8 時間）。実測値は未確認 | Phase 4 で Wi-Fi/Bluetooth 無効・輝度 30〜40%・振動有効の条件で計測 |
| タッチ座標の閾値 | 外周リング半径 170〜226px、最低移動角 6 度、キャンセル半径 145px は設計上の初期値。感度はデフォルト 36 度/ライフで Phase 1 確定済み、#38 で 5 / 10 / 20 ライフ/周から設定可能に拡張 | Phase 0 の実機テストで調整（感度は確定・設定可能化済み） |
| `atan2()` の符号 | 時計回りで角度が増えるか減るかは画面座標系に依存。現在の設計は「時計回り = 増加」だが符号の実際の向きは未確認 | Phase 0 の実機確認で確定。[開発ワークフロー](./03-dev-workflow.md) 参照 |
| 上下操作方向の整合性 | 上側プレイヤーは 180 度回転描画されるが、スライド方向（時計回り = 増加）が両プレイヤーで直感的に正しいかは未確認 | 実機テストで検証 |
| 長時間振動の不快感 | 10 点以上の変動で振動が連続すると不快になる可能性。高速入力時の間引き（6 点目以降は 2 ポイントごと）は MVP 後の調整項目 | 実機テストで判断 |
| UINT32_MAX 近傍のオーバーフロー | `int64_t` キャストで設計上は対応済み | 単体テストで検証必須 |
| BLE 実機成立性 | 製品ページでは無線仕様として Wi-Fi のみ明記。ESP32-S3 は BLE をサポートするが、この基板で BLE + 画面描画 + タッチの同時利用が可能かは未確認 | Phase 0 で検証（モバイル連携フェーズの前提条件） |
| PlatformIO ボード文字列 | `esp32s3box` は ESP32-S3-Box 向けの流用であり、M5StopWatch C152 用の公式定義は PlatformIO に未掲載 | 環境構築時に確認。[開発環境](./02-dev-environment.md) 参照 |
