このブラウザは書き込みに対応していません

このツールは Web Serial API を使用します。Chrome 89+ または Edge 89+ （Windows / macOS / Linux）でアクセスしてください。Safari・Firefox・Android の Chrome では書き込みできません。

① 書き込むバージョンを選択

書き込むファームウェアのリリースを選択してください。既定は最新の安定版です。 ファームウェアがまだリリースされていない場合は、リポジトリの CI で v* タグの Release を作成する必要があります。

選択中:

② ダウンロードモードに切り替える

  1. 電源ボタンを約 2 秒長押ししてください
  2. 緑色の LED が点灯したら、その場でボタンを離してください
  3. 書き込み待機状態（ダウンロードモード）に入ります
緑 LED が点灯しない場合
  • 長押しが 2 秒未満かもしれません。もう一度、約 2 秒長押ししてください
  • バッテリー残量が不足している可能性があります。USB-C で給電してからお試しください
注意:
  • 長押ししすぎると電源が切れます。電源が切れた場合は、電源ボタン短押しで電源を入れ、再度 2 秒長押ししてください
  • ダウンロードモードは無期限に待機するため、中断して放置するとバッテリーを消費し続けます。書き込みを中断する場合は、電源ボタン短押しで通常起動に戻すか、素早く 2 回押しで電源を切ってください

③ USB ケーブルで接続する

デバイスを USB-C ケーブルでパソコンに接続し、「接続」ボタンを押してポートを選択してください。

選択ダイアログでは「USB Serial」や「/dev/cu.usbmodem*」などと表示されるポートを選んでください。

ポートの一覧にデバイスが表示されない場合
  • 充電専用ケーブルを使っている可能性があります。データ通信対応のケーブルに交換してください
  • ほかのタブやシリアルモニタがポートを占有していると接続できません。すべて閉じてから再試行してください
  • ブラウザを再起動すると解決することがあります

④ チップを確認する

デバイスに接続してチップ情報を読み取っています…

書き込み先:

警告: 期待するチップ（ESP32-S3）と異なります。

接続したデバイスはダウンロードモード（USB Serial/JTAG）で動作していない可能性があります。 ステップ②に戻り、電源ボタン約 2 秒長押し（緑 LED 点灯）でダウンロードモードに切り替えてから再試行してください。

⑥ 起動してバージョンを確認

  1. 電源ボタンを短押ししてデバイスを起動してください
  2. 画面にライフカウンターが表示されることを確認してください
  3. About 画面のバージョンが と一致することを確認してください
起動しない場合
  • もう一度電源ボタンを短押ししてください（自動リセットのみでは起動しないことがあります）
  • それでも起動しない場合は、Boot ボタン（GPIO0）を押しながら USB-C ケーブルを抜き差しする強制ブートローダーモードで復旧を試みてください

書き込み内容の確認

フルフラッシュでは全消去を実行します。設定・ゲーム履歴（NVS）は消去されます。
警告: SHA-256 の照合元（sha256sums.txt）がリリースに含まれていないため、 ダウンロードしたファイルの破損・改ざんを検出できません。 書き込みを続行するのは、初回実機検証などリリース内容を把握している場合のみにしてください。

このページは Web Serial API（Chrome / Edge 対応）と esptool-js を使用しています。 書き込み中はブラウザのタブを閉じないでください。
